# Turkish-Kurdish AI Language Evaluation

## Project Overview
This independent project explores how AI language models interpret everyday conversations that mix Turkish and Kurdish, with a focus on regional expressions and code-switching in Central Anatolia.

## Objectives
- Identify misunderstandings in mixed-language conversations.
- Evaluate whether AI responses preserve the intended meaning.
- Examine regional vocabulary and contextual ambiguity.
- Document errors and suggest more accurate interpretations.

## Evaluation Method
The planned evaluation process includes collecting original or permission-cleared examples, testing AI responses, comparing interpretations with verified meanings, and documenting error categories.

## Current Status
Project initiated. Evaluation examples and verified results have not yet been published.

## Focus Areas
Multilingual AI Evaluation | Turkish-Kurdish Code-Switching | Language Quality Assurance | Regional Language Understanding
